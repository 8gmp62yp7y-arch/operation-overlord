OPERATION OVERLORD

Normandy, 6 June 1944. Land your troops, seize a small coastal strongpoint, establish a forward base and push inland to destroy the German bunker.

A classic isometric real-time strategy game. Select units, issue orders, construct buildings and command your assault.

COMMAND & ORDERS

Select a unit, then choose MOVE or ATTACK and click a destination or enemy. Drag on the map to select several units.

UNIT / BUILDING STATUS

No unit selected.
Select an Allied unit or building.

BUILD / REINFORCE

Secure the fortification to unlock base construction.

TACTICAL MAP

Gold = objective · Blue = Allied · Red = German

MISSION BRIEFING

1. Land on the beach.
2. Secure the coastal fort.
3. Build a forward base.
4. Destroy the inland bunker.
Controls: mouse/touch to select and command · WASD or arrow keys to pan the map · mouse wheel to zoom · On mobile, drag the map to pan. This is an original prototype using classic RTS-inspired artwork.
